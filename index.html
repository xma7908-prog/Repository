全网最全的小白私有化部署保姆级教程

Step 1. 一键全自动部署

/bin/bash -c "$(curl -fsSL https://get.docker.com | sh && docker run -d --name openclaw -p 18789:18789 -e LANG=zh_CN.UTF-8 --restart always openclaw/openclaw-ce:latest)"
🚫 复制了但没反应？
1. 确保在 Termius 或手机终端登录了服务器。
2. 必须开端口：在云服务器后台安全组开启 18789 端口！

Step 2. 深度配置百科 (避坑指南)

🖥️ 硬件要求与网络自检
设备系统要求关键点
云服务器Ubuntu 20+1核2G起步，推荐2核4G
个人电脑Win10/Mac需先运行 Docker Desktop
网络公网/内网飞书接入必须有公网IP
🔑 全平台 Key 申请与 Token 查看
ChatGPT Claude 字节豆包 阿里千问 DeepSeek
余额哪里看？ 各平台后台进入 Usage / Billing 即可查看 Token 消耗。私有化部署，Key 绝不外泄。
📱 飞书接入常见错误 (404/502)

1. 回调地址：http://IP:18789/api/feishu/event

2. 权限：搜索 im:message 开启所有权限。

3. 上线：配置完务必在飞书后台点击“版本管理与发布”。

🚀 如何更新版本 / 绑定域名

• 升级命令：

docker pull openclaw/openclaw-ce:latest && docker stop openclaw && docker rm openclaw && (粘贴上方安装命令)

• 域名访问：若绑定域名，访问地址为 http://你的域名:18789。
