1 软件下载与环境报错解决

Docker下载：Win直连 | Mac M系列 | Intel版

🛑 报错 1：安装后提示 "WSL 2 kernel update"？ 解法：这是缺少 Linux 内核补丁。点击弹窗里的链接下载并安装（大小约 15MB），重启即可。
🛑 报错 2：提示 "Virtualization not enabled"？ 解法：必须进入电脑 BIOS（通常是开机按 F2/Del），找到 Virtualization Technology 并设为 Enabled。

2 核心补丁：解决运行指令一直 Loading

不配这个，拉取镜像会永远超时！打开 Docker 设置 -> Docker Engine，在 JSON 中加入镜像源：

{
  "registry-mirrors": [
    "https://docker.m.daocloud.io",
    "https://huecker.io"
  ]
}

✅ 修改后点 Apply & Restart。这是解决“下载没用”的唯一办法。

3 核心：安装 OpenClaw 指令

在 CMD（Win）或终端（Mac）中粘贴运行：

docker run -d --name openclaw -p 8080:8080 -v openclaw_data:/app/data --restart always openclaw/openclaw:latest

🚩 访问地址：浏览器打开 http://localhost:8080

🛑 报错 3：无法连接到服务器/端口占用？ 解法：如果 8080 被占用，请将指令中的 -p 8080:8080 改为 -p 9090:8080，然后访问 9090 端口。

4 进阶：接入手机飞书/微信

进入 OpenClaw 后台 -> 通道设置 (Channels)：

飞书自建机器人

1. 在飞书开放平台创建应用，开启机器人功能。
2. 复制 App ID 和 Secret 填入管家后台。
3. 复制管家给的 Webhook 地址 填回飞书事件订阅。

个人微信接入

1. 选择微信通道，扫码授权。
2. 注意：必须用微信小号！禁止在群里高频刷屏，否则会被暂时限制登录。

5 灵魂：API Key、Base URL 与 Token 计费

1. API Key 获取

AI 的对话需要消耗 API Key。请扫码添加作者微信获取稳定、支持国内直连的中转 Key。

🛑 为什么填了 Key 还是报错/不回答？ 死穴解决：使用中转 Key 时，在后台“模型设置”里，必须把默认的 api.openai.com 地址改为中转商地址（如 https://api.chzh.com/v1）。不改地址，国内网络永远无法连接。
2. Token 计费说明
  • 消耗概念：AI 按照 Token 计费，1k Token 约等于 700 个汉字。
  • 查看消耗：在管家后台左侧点击“日志/额度”，可以实时看到每条对话消耗了多少 Token。
  • 省钱技巧：在 AI 角色预设中加入“请简短回答，不要废话”，能帮你节省 30% 以上的费用。
