1 避坑：哪些电脑【绝对不能】装？

  • 内存不足 8GB：Docker 运行后系统会极度卡顿甚至死机（推荐 16GB）。
  • 32 位操作系统：只支持 64 位系统，且不支持 Win7 及以下版本。
  • 虚拟化未开启：CMD 输入 systeminfo | findstr "Virtualization"，必须显示“是”。
  • 虚拟机嵌套：严禁在虚拟机里再装 Docker，99.9% 会报错安装失败。

* 若硬件不达标，请直接选用【方案 C】云服务器版，省心省力。

2 核心：Docker 软件下载与环境修复

1. 软件极速下载：

  • Windows：官方直连下载（如慢，请扫码找作者获取国内网盘分流）。
  • Mac：M1/M2/M3版 | Intel版。

2. 环境报错修复：

💡 安装后弹出 "WSL 2 kernel update"？请点击弹窗内的链接下载 Linux 内核补丁，安装后重启即可。如果提示 VT 禁用，请进 BIOS 开启虚拟化。

3 核心补丁：解决运行代码一直 Loading

这是解决你今天卡两小时不动的唯一解药！

打开 Docker Desktop -> Settings -> Docker Engine，在右侧 JSON 代码框加入：

{
  "registry-mirrors": [
    "https://docker.m.daocloud.io",
    "https://huecker.io",
    "https://dockerhub.timeweb.cloud"
  ]
}

✅ 点击 Apply & Restart。不配这个，拉取 OpenClaw 镜像会永远超时。

4 核心：一键安装 OpenClaw (核心指令)

方案 A：WINDOWS / Mac

确保 Docker 绿色运行后，打开 CMD 或 终端粘贴回车：

docker run -d --name openclaw -p 8080:8080 -v openclaw_data:/app/data --restart always openclaw/openclaw:latest
方案 B：云服务器 (Ubuntu 22.04)

登录 SSH 终端后直接粘贴（含 Docker 环境全自动安装）：

curl -fsSL https://get.docker.com | bash && sudo docker run -d --name openclaw -p 80:8080 -v openclaw_data:/app/data --restart always openclaw/openclaw:latest
⚠️ 云端必看：必须在云后台防火墙开启 80 端口！

🚩 访问地址：本地 http://localhost:8080 | 云端 http://你的公网IP

5 灵魂：API Key 获取与接口配置

1. 如何获取 API Key？

官方 Key 难搞？扫码添加作者，获取稳定、免翻墙、极速响应的国内直连 API 中转地址。

2. 接口转发 (Base URL) 怎么填？

最核心细节：使用中转 Key 时，务必将接口地址改为：https://中转域名/v1。默认的 api.openai.com 国内无法访问，不改会报错！
