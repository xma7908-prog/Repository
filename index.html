🔍 第一步：设备自动化“体检”

在安装前，请先确定你的设备是否支持虚拟化（AI 运行的必要条件）。

1. 按下 Win + R，输入 cmd 回车。

2. 复制并执行下方体检代码：

systeminfo | findstr "Virtualization"

✅ 显示“已启用”：推荐【方案 A】。 ❌ 显示“否”：推荐【方案 B】。

📦 第二步：方案 A - Windows 本地一键部署

适用人群：高性能电脑用户

我们为你准备了自动化防护脚本。它会自动检测权限、唤醒 Docker 并清理旧冲突。

  1. 下载并安装 Docker Desktop。
  2. 在桌面新建记事本，粘贴下方脚本，保存为 一键启动.bat 并运行。
@echo off
title 龙虾管家一键引擎
color 0A
:: 自动获取管理员权限...
(按教程复制完整 .bat 脚本内容)
docker run -d --name openclaw -p 8080:8080 --restart always openclaw/openclaw:latest
start http://localhost:8080
pause

☁️ 第三步：方案 B - 云服务器 Linux 极速部署

适用人群：追求 24h 永远在线的用户

登录你的服务器（Ubuntu 系统），直接鼠标右键粘贴下方这一行长代码：

curl -fsSL https://get.docker.com | bash && sudo docker run -d --name openclaw -p 80:8080 --restart always openclaw/openclaw:latest
⚠️ 必做细节：请务必去云服务器后台的【防火墙/安全组】中，手动放行 80 和 8080 端口，否则无法打开页面！
