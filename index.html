第一章：设备“一键体检”

小白必做！确认你的电脑是否具备 AI 运行的基本环境：

WINDOWS 适用

1. 按 Win + R 键，输入 cmd 并回车。

2. 粘贴以下代码：systeminfo | findstr "Virtualization"

结果分析：
✅ 显示“已启用/Enabled”：推荐【方案 A】本地直接部署。
❌ 显示“否”或报错：推荐【方案 B】购买云服务器部署，免折腾。

第二章：云服务器购买与设置 (推荐方案)

如果你想让 AI 24小时不关机，且手机能随时远程控制：

  • 选购建议：去腾讯云或阿里云搜索“轻量应用服务器”。
  • 镜像系统：务必选择 Ubuntu 22.04。
  • 关键细节：去云后台【防火墙】添加规则，开放 80 和 8080 端口。

第三章：终极一键安装引擎

方案 A：云服务器 (Linux) 一键代码

登录远程黑窗口，直接粘贴执行：

curl -fsSL https://get.docker.com | bash && sudo docker run -d --name openclaw -p 80:8080 --restart always openclaw/openclaw:latest
方案 B：本地电脑 (Windows) 一键脚本

先安装 Docker Desktop，然后复制下方内容存为 启动.bat 运行：

@echo off
docker rm -f openclaw >nul 2>&1
docker run -d --name openclaw -p 8080:8080 --restart always openclaw/openclaw:latest
start http://localhost:8080
