Step 1. 复制一键部署代码

/bin/bash -c "$(curl -fsSL https://get.docker.com | sh && docker run -d --name openclaw -p 18789:18789 -e LANG=zh_CN.UTF-8 --restart always openclaw/openclaw-ce:latest)"
🚫 避坑提醒 1：端口必须开！
请在云服务器后台防火墙手动添加并放行 18789 端口，否则无法访问后台！

Step 2. 核心避坑百科

🖥️ 系统兼容性与硬件自检
❌ 避坑金句：不支持 Win7/8/9 及老旧系统，推荐使用云服务器或 Win10/11。
设备推荐系统建议
云服务器Ubuntu 20.04+最省心，24h在线
个人电脑Windows 10/11必须安装 Docker Desktop
配置2核 2G 内存1核1G运行会比较吃力
🌐 为什么非要【公网 IP】不可？
⚠️ 避坑金句：接入飞书必须使用带【公网IP】的服务器，个人家用宽带通常无法直接接入。

飞书通过互联网发送信号给你的机器人，如果没有公网IP，飞书就找不到你的服务器。如果你一定要用家用电脑，需自学“内网穿透”。

🔑 模型 Key 申请与额度查看
ChatGPT (国外) Claude (国外) 字节豆包 (国内) 阿里千问 (国内) DeepSeek (性价比)

💡 Token 怎么看？ 请在各官网后台找 Usage / Billing 查看余额。1000 Token 约等于 750 个汉字。

📱 飞书接入专题 (404/502 错误解答)

1. 回调地址：http://你的IP:18789/api/feishu/event

2. 一定要点发布：配置完飞书权限后，必须在“版本管理与发布”里点击上线，否则机器人不生效！

🔄 版本如何升级？域名如何访问？

• 升级：停止并删除旧容器后重新运行 Step 1 代码即可。

• 域名：若绑定域名，访问地址为 http://你的域名:18789。
