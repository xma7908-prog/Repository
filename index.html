🦞 OpenClaw 部署助手

第 1 步：一键安装

在 Termius 中粘贴运行：

/bin/bash -c "$(curl -fsSL https://get.docker.com | sh && docker run -d --name openclaw -p 18789:18789 -e LANG=zh_CN.UTF-8 --restart always openclaw/openclaw-ce:latest)"

第 2 步：获取大模型 Key

🌐 国外模型 (GPT/Claude)

1. 访问 OpenAI 官网。
2. 点击 "Create new secret key"。
3. 注意： 需要科学上网，且账户需有余额。

🇨🇳 国内模型 (豆包/通义千问)

豆包 (字节): 访问 火山引擎，创建“接入点”，复制 API Key。
千问 (阿里): 访问 百炼平台，点击“API-KEY管理”直接生成。

第 3 步：手机端聊天控制

🔹 接入飞书 (最推荐)

1. 在 飞书开放平台 创建企业自建应用。
2. 开启“机器人”功能。
3. 在 OpenClaw 后台填入 App ID 和 Secret。
4. 设置事件回调： 地址填 http://服务器IP:18789/api/feishu/event。

🟢 接入微信/个微

使用 Wechaty 插件。需在 OpenClaw 设置中选择微信协议，扫描后台生成的二维码即可。风险提示： 个人微信机器人有封号风险，建议用小号。

安装完成后，浏览器访问 http://服务器IP:18789 即可进入图形化后台进行以上配置。
